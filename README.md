# Absensi Wajah Siswa - SMP NEGERI 1 KALIPARE (2026/2027)

Semua file di paket ZIP ini berada langsung di root (tanpa folder) agar mudah diunggah lewat HP ke GitHub.

## Isi File (10 File Flat Tanpa Folder)
- `index.html` & `scan.html`: Halaman pemindai absensi wajah otomatis + mode Sholat Dhuhur, Jum'at & Keputrian (mulai 11:45).
- `master_data.json`: Data 472 siswa (2 vektor wajah 128-D terdaftar).
- 6 file model AI deteksi wajah (`.json` & `.bin`).

## Cara Upload ke GitHub lewat HP
1. Ekstrak file ZIP di HP Anda (semua 10 file berada dalam 1 level tanpa sub-folder).
2. Buka repository GitHub Anda di browser HP, pilih **Add file** -> **Upload files**.
3. Pilih semua 10 file hasil ekstrak lalu tekan **Commit changes**.
4. Buka **Settings** -> **Pages** -> pilih Branch **main** dan folder **/ (root)** -> **Save**.
5. Buka link GitHub Pages Anda untuk menjalankan absensi wajah.
